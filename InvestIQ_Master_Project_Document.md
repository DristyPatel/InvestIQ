# 2. Project Vision

InvestIQ is an AI-powered corporate investment research platform designed to automate the complete investment research workflow.

Instead of manually reading annual reports, analysing company fundamentals, calculating ratios, comparing competitors, and creating reports, InvestIQ performs these tasks through AI-assisted workflows.

The long-term goal is to build a commercial-quality fintech application that helps investment professionals make better investment decisions faster.

# 11. Development Principles

InvestIQ must follow professional software engineering practices.

Every module must be

* Modular
* Reusable
* Scalable
* Maintainable

Never generate temporary code.

Never generate placeholder architecture.

---

# 12. Coding Standards

Variable names must be meaningful.

Functions should have one responsibility.

Avoid duplicate logic.

Use comments only when necessary.

Backend must be modular.

---

# 13. Project Folder Philosophy

Frontend and backend remain separated.

Never mix HTML with backend logic.

Backend communicates with frontend using APIs.

---

# 14. Security Rules

Passwords must never be stored directly.

Always hash passwords.

Validate every user input.

Never trust frontend validation.

Implement secure sessions.

---

# 15. AI Philosophy

AI should assist the user.

It should never replace the user's decision.

Every recommendation should include reasoning.

The AI layer should be replaceable (Gemini ↔ OpenAI) without changing the frontend.

---
